# Student Scholarship Information System

PBL Project – Group B11, BTech CSE (AI), NIET Greater Noida
Course: Innovation and Entrepreneurship (DMB0101)
Faculty: Dr. Sanjay Sudriyal

## About
A system that helps students find scholarships they are eligible for.
A student enters course, category, family income, marks and state,
and the system shows a match score and the reasons for any failed rule.
Supports SDG 4 (Quality Education) and SDG 10 (Reduced Inequalities).

## What is in this repository
- matcher.py : MVP matching engine (rule-based scoring)

## How to run
python matcher.py

## Note
The scheme used (Sample Scheme X) is made-up sample data to
explain the logic. It is not a real scholarship scheme.
